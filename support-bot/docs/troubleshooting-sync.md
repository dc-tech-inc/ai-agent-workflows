# Troubleshooting backups

## Backup is paused

The app pauses backups when the battery is low or when your computer is on battery power, if Pause on battery is on. Plug in the computer or switch the option off under Settings, then Power.

## Error FB-204

Error FB-204 means the network blocked the connection. Allow outgoing traffic on port 443 to the Fernwood servers in your firewall or proxy, then retry.

## Error FB-310

Error FB-310 means a file was locked by another application. Close the application that is using the file. The app retries locked files automatically every hour.

## Large files

A single file can be up to 100 GB. Larger files are skipped and listed in the activity log with the reason.

## Slow uploads

You can limit upload speed under Settings, then Bandwidth, to keep your connection responsive. Choose Unlimited to upload as fast as your connection allows.

## Contacting support

If a problem remains, open Help, then Send diagnostics, and attach the report to a support request. The report contains no file contents.
