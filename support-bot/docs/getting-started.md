# Getting started with Fernwood Backup

Fernwood Backup is a fictional cloud backup product, written for this repository so the support bot has something to answer about.

## Installing the desktop app

Download the Fernwood desktop app for Windows, macOS or Linux from the downloads page and run the installer. The app needs about 150 MB of disk space and starts automatically when you sign in to your computer.

## Your first backup

After you sign in, the app proposes your Documents, Pictures and Desktop folders. You can add or remove folders at any time under Settings, then Folders. The first backup starts within 15 minutes of choosing folders and runs in the background.

## The free plan

Every account starts on the Free plan, which includes 5 GB of storage and keeps file versions for 7 days. No credit card is needed to create a Free account.

## Files that are skipped

Temporary files, system caches and folders named node_modules are skipped by default. You can turn these exclusions off under Settings, then Exclusions.
