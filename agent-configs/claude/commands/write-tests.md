description: Add focused tests for a file or function
---
Write tests for: $ARGUMENTS

1. Read the code under test and the existing tests next to it. Follow their style and helpers.
2. List the behaviours worth pinning down: the normal path, each branch, boundary values, and the error cases.
3. Write one test per behaviour with a name that states it. Test through the public interface, not private details.
4. Run the tests and show the result. If a test fails because of a real bug, report the bug instead of bending the test.
